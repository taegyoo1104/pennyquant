# 토스 20거래일 분봉 조회 검사

프로젝트를 설치한 로컬 Python 환경에서 기존 `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET` 환경변수를 사용한다. 프로젝트 `.env`도 지원하며 기존 환경변수가 우선이다. 키를 채팅이나 Git에 올리지 않는다. 계좌 순번·MySQL·OpenAI 설정은 필요 없다.

같은 토스 클라이언트를 사용하는 수집기를 먼저 종료한다. 새 OAuth 토큰 발급은 이전 토큰을 무효화할 수 있다. 환경변수를 최근 등록했다면 새 터미널을 열거나 IDE를 재시작한다.

```sh
python -m sessionquant.candle_probe --symbol AAPL --sessions 20
```

실행 시각까지 종료된 최근 20거래일을 XNYS 달력으로 고른다. 휴장일·조기 폐장을 반영하고, 당일 진행 중인 세션은 제외한다. 각 거래일의 장 종료 시각에서 과거 방향으로 최대 10페이지(페이지당 200개)를 조회한다. 인증 POST 외에는 시세 GET만 호출한다. 기존 어댑터의 초당 1회 속도 제한과 최대 3회 읽기 재시도를 사용한다. 중단하려면 Ctrl+C를 누른다.

화면에 거래일별 확보 분봉/예상 분봉, 누락, 충돌, 종료 사유가 출력된다. 결과는 `data/toss-history-probe-<symbol>-<UTC시각>.json`에 새 파일로 저장한다. 정상 정규장은 390분, 조기 폐장일은 해당 달력의 분 수를 기대한다. 페이지 경계의 동일 분봉은 중복 집계하지 않으며, 서로 다른 OHLCV가 반환되면 충돌로 표시한다. 누락을 거래량 0으로 채우지 않는다.

- 종료 코드 0: 요청한 모든 거래일의 정규장 분봉 확보, 충돌 없음.
- 종료 코드 1: 누락, 충돌, 조회 한도, API 오류 등으로 전체 확보 미확인. 부분 보고서를 확인한다.
- 종료 코드 2: 인증 환경변수 누락 또는 잘못된 CLI 인자.

`history_complete=true`는 해당 종목·조회 시점의 분봉 확보 여부만 의미한다. 100종목 전체 확보, 거래량 집계 시장 범위, 분할·병합 조정 정책, 현재 데이터와의 비교 가능성, RVOL 운영 적격성을 인증하지 않는다. 따라서 `rvol_comparability_verified`는 항상 false로 둔다. 문서상 캔들의 종료 시각 규칙과 현재 프로젝트의 정수 거래량 검증을 사용한다. API 응답이 이 계약을 충족하지 않으면 오류로 보고하며 임의 변환하지 않는다.

이 도구는 DB·실주문·LLM을 호출하지 않고 기존 매매 게이트나 적격성 설정을 바꾸지 않는다. 공유할 결과는 생성된 JSON이며 인증키·토큰·계좌정보는 포함하지 않는다.
