# SessionQuant 방향과 단계 경계

확인일: 2026-11-15. 사용자 요청으로 과거 대화와 단계별 첨부를 현재 코드와 대조했다.

## 작업 기준

사용자가 이번 대화에서 재확인한 기준은 **실제 작업 순서·세부 요구사항·완료 기준은 첨부한 단계별 기획서를 따른다**는 것이다. 일반 공유 대화는 프로젝트의 대략적인 목표와 배경을 이해하는 참고 자료다. 대화 속 과거 예시·제안·작업 지시문으로 단계 기획서를 덮어쓰거나 후속 구현을 시작하지 않는다. 현재 대화의 최신 사용자 지시(KIS 제외, 초기 로컬 운영 후 GCP 이전)를 반영하고, 승인받은 해당 단계의 첨부 기획서와 현재 코드를 대조해 진행한다.

## 확인한 자료

- [이전 Codex 대화](https://chatgpt.com/s/cx_6af911a2e8a081918790f0de398d547b): 공개 공유 대화 본문을 읽었다. PennyQuant에서 SessionQuant로 전환한 목적, 로컬 MySQL·Paper 우선, 토스 연결과 단계별 작업 이력을 확인했다. 개인 접속 정보와 대화 전문은 저장소에 복사하지 않는다.
- [기획 대화](https://chatgpt.com/share/6af9093e-74dc-83ec-962b-ff3c8ff4ef3e): 07 최초 작업에서는 HTTP 503/timeout으로 읽지 못했으나, 사용자가 다시 공유한 뒤 공개 공유 데이터 경로에서 본문을 확보했다. 페니스탁에서 S&P 500으로의 전환, 시총 100→집중 20, 06·07 개정, 금리·유가 감시와 LLM 분리, UI 상세 분리, 단계별 승인 결정을 대조했다. 후반 KIS 검토는 사용자의 취소에 따라 적용하지 않는다. 대화 속 과거 코드 진단·요금·API 설명은 당시의 참고 자료이며 현재 실연동 검증을 대신하지 않는다.
- 사용자가 다시 제공한 16개 첨부: 읽는 순서, 전체 로드맵, 00 기준선, 01~10 단계, 08A, 06·07 개정, 금리·유가 개정. **단계별 작업 계획의 기준 문서**다. 07 완료 후 사용자가 **08 진행**을 승인했다. 이후 사용자가 08A도 승인했다. 09/10은 별도 승인 후 적용한다.
- [HANDOFF](../../HANDOFF.md)의 06 후속 검증 완료 기준 `0fa5ad4`에서 이어서 작업했다. 첨부의 과거 기준 커밋으로 현재 작업을 되돌리지 않았다.

## 유지할 목표

S&P 500 장중 추세 매매를 개발한다. 시가총액 감시 최대 100종목에서 집중 최대 20종목을 선정하고, 확정된 5분·15분봉, SPY·QQQ 국면, 거래 적격성·RVOL, 비중·위험·청산 조건을 함께 확인한다. 뉴스 없이도 기술적 조건으로 후보가 될 수 있다. 현금 유지와 무거래도 정상 결과다.

초기 자본 $100, 금액·비율 기반 소수점 주문, 최대 보유 5종목과 초기 2종목 중심, 추세·지지·위험 예산을 확인한 추가매수 최대 1회를 초기 가설로 유지한다. 시가총액은 감시 대상을 정하는 기준이며 실제 진입 우선순위는 기술적 조건·유동성·위험으로 판단한다. 감시목록 밖의 기존 보유·미체결도 위험 감시를 유지한다.

토스는 시세·계좌·주문 연결 경로로 유지한다. **KIS 검토·연결은 사용자 취소를 반영해 범위에서 제외한다.** 주문 전달과 체결, 실제 보유와 Paper 장부를 구분하며 실계좌 값을 합성 데이터로 채우지 않는다.

기업·거시 뉴스와 LLM은 사실과 위험 분석을 보조한다. 제목·발견 목록·출처 미확인 자료로 확정 사건을 만들지 않는다. LLM에는 주문 도구를 제공하지 않는다. 키·크레딧·뉴스가 없거나 분석에 실패해도 차트 처리와 기존 포지션의 손절·청산 작업은 독립적으로 진행한다. 이미 검증된 위험 제한은 유지한다.

기업 뉴스는 SEC·공식 IR/RSS와 무료 Alpaca REST 보조 자료, 거시는 공식 경제기관·GDELT 발견 경로를 사용한다. 무료 Alpaca 지연을 유료 실시간 권한으로 간주하지 않는다. LLM 입력·출력·근거·호출·토큰·비용 연결과 중복 방지가 07의 핵심이다. `gpt-6-luna`는 비교 후보이며 기존 primary를 바꾸려면 품질·비용·지연을 먼저 평가한다.

FRED 금리·유가 자료는 일별 배경, IEF/TLT/SHY/USO 등은 장중 ETF 대용 지표다. ETF 수익률을 금리 bp나 원유 현물 가격으로 환산하지 않는다. 선택적 이벤트 LLM 해설은 기본 OFF이며 자동 주문·강제 청산에 연결하지 않는다.

## 개발 순서와 현재 범위

사용자의 이번 대화 최신 지시는 **초기에는 로컬 PC·로컬 MySQL에서 실행하고, 나중에 GCP로 이전**하는 것이다. 초기 Paper 기록·관찰·검증을 로컬에서 진행한다. 토스 소액 실거래는 별도 승인 후 검증하며, GCP 이전과 실거래 활성화도 각각 승인 범위를 확인한다. 클라우드에서 Paper를 실행하는 선택도 실주문 활성화와 구분한다. 현재 GCP 자원 생성·배포는 요청하지 않았다. 기능 구현, 실제 계정 접근, 장기간 성과 검증, 운영 승인은 각각 따로 확인한다.

| 단계 | 현재 상태 |
|---|---|
| 00~05 | 기존 구현·기준 유지. [종합 검토](REVIEW_00_08.md)에서 시계/비용 보완과 CI 구성 추가 |
| 06 | `0fa5ad4`의 격리 회귀 검증 완료 기준 유지. 실제 공급자 운영 조건은 미검증 |
| 07 | 사용자 승인 범위. [LLM 감사·근거·평가·비용 구현](stages/STAGE07_LLM.md) 및 격리 검증 |
| 08 | 사용자 승인 범위. [후보·뉴스·업종·포트폴리오 연결](stages/STAGE08_CANDIDATES.md) 및 격리 검증 |
| 08A | 사용자 승인 후 6화면·간결한 메인·기존 큐 제어 UI 구현. 실데이터/실거래 운영 검증 별도 |
| 09 / 10 | 공통주문·실거래 연결·로컬 운영 승인은 다음 승인 대기 |
| GCP | 초기 로컬 운영 이후 이전 예정. 환경·비용·Paper/실거래 범위를 별도 확정한 뒤 진행 |

07·08에서는 기존 메인 5개 탭을 보존하고 LLM 감사·후보 선정 조회를 연결한다. 08A 전체 화면 개편을 함께 수행하지 않는다. 과거 문서의 **Phase 5 실거래 기능**과 새 로드맵의 **05 기록·백테스트**는 번호 체계가 다르므로 파일의 실제 기능과 실행 경로를 확인한다.

최종 UI는 메인에 계좌·필수 비용·보유·최근 거래·관련 뉴스를 간결하게 두고, 상세 지표·전체 거래·뉴스·LLM 감사는 별도 탭으로 분리하는 08A 첨부 기획서를 따른다. 전체 기획서로 단계 간 의존성을 확인하되, 최신 사용자 요청이 승인한 단계까지만 구현한다. 09/10 이후 단계별 승인 경계는 유지한다.
