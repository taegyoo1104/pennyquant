# 최신 기획서 대비 00~04 점검

승인 범위는 기존 00~04 점검, 02 보완 후 04 보완 및 회귀 검사다. 05~10은 의존 관계 확인용이며 구현·외부 설정 변경 승인으로 간주하지 않는다.

| 단계 | 기존 구현과 이번 판단 |
|---|---|
| 00 | 현재 실행 경로 문서·테스트 명령은 있다. `.github/workflows` 기반 전체 CI는 미구축이다. 이번에는 점검 결과만 기록한다. |
| 01 | 시총 100·집중 20·보유 우선 순환·이력 복구는 구현되어 있다. 동일 기준일의 USD 발행사 시총 공급 자료는 실제 연결 미검증이다. 합성 입력을 실데이터로 사용하지 않는다. |
| 02 | 엄격 적격성·분봉·RVOL·조회 예산 검사가 있다. 이번에 시장 참고 ETF 관측·권한 분리·별도 원장을 보완한다. 실제 계좌 권한·기업행동·20일 이력 검증은 남는다. |
| 03 | `market_v2` 시장가 근사와 취소 지연·잔량·장부 감사가 있다. 버전 1은 `legacy_limit_v1`로 별도 복구한다. 기존 장부를 자동 변환하지 않는다. |
| 04 | 작업 중이던 전략·위험·청산 보완을 보존한 뒤 02 검증 후 복원했다. 최신 거시 참고 위험 감시는 관찰 전용으로 추가했다. 변경·검증·미완료 항목은 [단계 04 결과](stages/STAGE04_STRATEGY_RISK_EXIT.md)를 따른다. |

기존 네 전략, 시장 국면, 시작 버튼·중지·보유 종목 매도 경로를 유지한다. `run`은 PAPER_LOCAL, `run-account`는 실제 계좌 조회, `live-local`은 별도 제한적 주문 검증 경로다. 이번 작업으로 자동 실거래를 활성화하지 않는다. 사용자 PC MySQL·계좌·API 키에는 접근하지 않는다.

원문 뉴스 수집·LLM 모델·전체 UI 재설계·실제 데이터 기록 백테스트 확장·실거래 연결·GCP 작업은 이번 범위가 아니다. 다음 05단계는 이번 결과 보고 후 별도 승인을 기다린다.
