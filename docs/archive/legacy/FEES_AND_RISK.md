# 수수료·익절·손절·일일 손실 관리

확인일: **2026-11-13**. 아래 비율은 수익을 보장하거나 최적화한 매매 조건이 아니라, 비용을 포함해 동작을 검증하기 위한 초기 설정입니다.

## 토스증권 미국주식 수수료

| 항목 | 확인한 기준 | 설정 |
|---|---|---|
| 매수 매매수수료 | 거래금액의 0.1% | `commission_buy_bps: 10.0` |
| 매도 매매수수료 | 거래금액의 0.1% | `commission_sell_bps: 10.0` |
| 소액 주문 면제 | **주문 건별 총 체결금액 $10 이하**이면 매매수수료 면제 | `commission_free_notional: 10.0` |
| 매도 SEC Fee | 매도금액의 0.00206%, 최소 $0.01 | `sell_regulatory_bps: 0.206`, `sell_regulatory_min: 0.01` |

공식 근거:

- [토스증권 Open API 안내](https://home.tossinvest.com/ko/open-api): 미국주식 0.1% 및 $10 이하 주문 면제, 세금·제비용 별도.
- [토스증권 수수료 FAQ 검색](https://corp.tossinvest.com/ko/faq?page=1&searchTitleKeyword=%EC%88%98%EC%88%98%EB%A3%8C&tab=101): 매도 SEC Fee와 최소 금액. 앱에서는 증권 → 메뉴 → 주식 → 수수료에서 본인 계정에 적용되는 조건을 확인합니다.
- [SEC 2026 수수료 공지](https://www.sec.gov/rules-regulations/fee-rate-advisories/2026-2): 2026-04-04부터 매도금액 $100만당 $20.60. 이후 공지로 변경될 수 있습니다.

소액 면제 여부는 체결 한 번의 금액이 아니라 **동일 주문의 누적 체결금액**으로 계산합니다. 예를 들어 한 주문이 $4씩 세 번 체결되면 총 $12이므로 매매수수료가 발생합니다. $10 이하 매도 주문도 SEC Fee까지 면제되는 것은 아닙니다.

프로젝트의 `toss_us` 비용 모델은 예산을 보수적으로 잡기 위해 각 비용을 센트 단위로 올림합니다. 토스의 실제 반올림·최소 단위·계정별 할인과 차이가 있을 수 있으므로 **추정값**입니다. 실제 체결 수수료·세금이 제공되면 실거래 장부는 그 값으로 보정합니다. 비용이 아직 확정되지 않은 실거래 주문이 있으면 신규 진입을 보류합니다.

추가 주당 비용은 `sell_per_share_fee`, `sell_per_share_max`로 설정할 수 있으며 기본값은 0입니다. 확인하지 않은 TAF를 토스의 확정 추가 비용으로 가정하지 않습니다. 환전 비용과 연간 양도소득세는 주문별 비용 모델에 포함하지 않았습니다. 실제 계정 수수료, 제비용 및 적용일을 확인한 뒤 설정을 갱신하세요.

## 기본 위험 한도

[설정 파일](../../../sessionquant/config/strategy.yaml)의 주요 기본값입니다. 금액 단위는 USD입니다.

| 설정 | 기본값 | 의미 |
|---|---|---|
| `initial_cash` | `70.0` | 이 전략에 배정하는 시작 자금 |
| `max_positions` | `5` | 보유 종목과 미체결 매수 주문의 종목 합계 상한 |
| `max_entries` | `10` | 하루 접수된 신규 매수 주문 상한. 미체결·취소 주문도 포함 |
| `risk_per_trade` | `0.01` | 거래당 자금 대비 위험 예산 1% |
| `stop_pct` | `0.05` | 비용 반영 순손실 약 5%에서 손절 주문 검토 |
| `take_profit_pct` | `0.10` | 비용 반영 순이익 약 10%에서 익절 주문 검토 |
| `daily_loss_pct` | `0.02` | 거래일 시작 평가자산 대비 손실 2%에서 신규 매매 중단 |
| `max_consecutive_losses` | `2` | 연속 손실 거래 2회에서 당일 신규 매매 중단 |
| `fee_model` | `toss_us` | 위 토스 비용 추정 모델 사용 |
| `exit_price_policy` | `net` | 매수·매도 비용을 반영한 순손익으로 청산 기준 계산 |
| `slippage_bps` | `10.0` | 체결가가 불리하게 0.1% 움직이는 추정 반영 |

최대 5개는 채워야 하는 목표가 아닙니다. 뉴스·시세·전략·위험 조건이 충족되지 않거나 정수 주식 수량으로 위험 예산을 맞출 수 없으면 **0개를 보유하고 거래하지 않을 수 있습니다.**

## 익절·손절 계산

`net` 정책은 실제 매수 체결금액과 매수 수수료를 원가로 잡고, 예상 매도 수수료·SEC Fee·불리한 체결가 변화를 차감한 매도 대금으로 순손익을 계산합니다. 따라서 가격이 단순히 10% 올랐다고 바로 순수익 10%가 되는 것은 아닙니다. 매수의 호가 비용은 실제 매수가에 반영되고, 매도 판단에는 매수호가인 bid를 사용합니다.

부분 체결로 보유 수량·평균 매수가·매수 비용이 달라지면 손절·익절 기준을 다시 계산합니다. 대시보드의 손절·익절 가격과 손익분기 가격은 이 계산에 따른 **매도 주문 검토용 bid 기준값**입니다.

### 10% 이전의 조기 청산

10%는 고정 익절 목표이며 최대 수익률 제한이나 반드시 기다려야 하는 수익률이 아닙니다. `early_exit_enabled: true`가 기본값이며, 아래 조건도 별도로 보유 종목에 적용합니다.

- **하락 신호에 의한 이익 보호:** 현재 세션의 연속된 완성 1분봉 4개 이상에서 최신 종가가 VWAP과 직전 봉 저가 아래이고, 직전 종가보다 하락했으며, 거래량이 앞선 3개 봉 평균의 1.2배 이상이면 청산을 검토합니다. 최신 매도 호가에서 예상 매도 비용·슬리피지까지 차감한 순이익이 양수일 때 10% 전에도 매도 주문을 만듭니다.
- **중대한 악재에 의한 위험 청산:** 검증된 종목·출처·원문 근거, 분석 완료 시각과 사건 확정 여부를 확인한 중요도 HIGH의 부정 사건은 손익과 관계없이 청산을 요청할 수 있습니다. LLM이 추출한 사건의 확정 상태·근거·신뢰도·추가 확인 필요 여부를 검증합니다. 소문·UNKNOWN·단순 MIXED·낮은 신뢰도나 키워드만으로 강제 매도하지 않습니다. 규칙에서 위험 문구만 발견한 경우에는 경고·신규 진입 차단으로 제한하며, OpenAI 키가 없으면 이 사실 추출을 통한 강제 청산은 수행하지 않습니다. Alpaca 보조 자료는 단독 신규 진입을 승인하지 않지만 충분히 검증된 중대한 악재의 보호 청산에는 사용될 수 있습니다.

예를 들어 비용 차감 후 +3%에서 하락 신호가 확인되면 10%를 기다리지 않고 이익 보호 매도를 요청합니다. 같은 +3%라도 하락·악재 신호가 없으면 기존 목표와 손절 조건으로 보유합니다. 악재로 -1%에서 매도하면 이는 익절이 아닌 위험 청산이며 실제 손익은 손실로 기록합니다.

수익 확인 전의 기술 신호 유효기간은 `early_exit_max_signal_age_seconds: 120`입니다. 이익 보호 청산이 확정되면 부분 체결·주문 만료·재시작 뒤에도 해당 포지션이 완전히 청산될 때까지 의도를 유지합니다. 요청 뒤 가격이 내려가도 보호 요청을 취소하고 수익 회복을 기다리지 않습니다. 실제 체결 결과가 손실일 수 있으므로 조기 익절을 보장하지 않습니다. 오래된 호가나 진입 이전에 끝난 봉으로 매도하지 않습니다.

진입 스캐너가 해당 종목을 제외하거나 신규 진입이 중지된 상태여도 보유 종목의 청산 평가는 계속됩니다. 기존 매도 주문이 있으면 중복 매도하지 않고, 실제 주문의 취소는 확인 후에 다음 주문을 진행합니다. 주문 화면에는 고정 익절·손절, 하락 신호 이익 보호, 악재 위험 청산의 사유를 구분합니다. 이전 버전 DB는 새 설정의 기본값만 보완해 잔고·보유·중지 상태를 유지합니다.

손절 가격은 최대 손실을 보장하지 않습니다. 기준에 도달하면 로컬 프로그램이 지정가 매도 주문을 만들며, 주문 후 별도 체결 확인이 필요합니다. 급락·갭·거래정지·호가 부족·통신 장애가 있으면 주문이 체결되지 않거나 계획보다 큰 손실이 발생할 수 있습니다. 프로그램 종료 중에는 로컬 감시가 동작하지 않습니다.

## 일일 손실 한도와 알림

일일 손실은 실현손익뿐 아니라 **보유 포지션의 평가손익과 비용 추정**을 포함한 전략 장부 평가자산으로 판단합니다. 예를 들어 거래일 시작 장부가 $70이면 기본 2% 한도는 약 $1.40입니다. 손실 한도는 미국 뉴욕의 거래일 기준으로 관리합니다.

실거래의 장부는 `initial_cash`와 확인한 USD 매수 가능 금액 중 작은 값으로 시작하는 **전략 배정 자금**입니다. 토스 계좌 전체 자산이나 다른 수동 매매의 손익을 대신 계산하는 값이 아닙니다. 다른 주문·보유와 장부가 맞지 않으면 신규 진입을 중단하고 대조 결과를 확인합니다.

한도에 도달하면 다음처럼 동작합니다.

1. 당일 신규 매수를 중단하고 미체결 매수의 취소를 처리합니다. 실거래 취소는 증권사 확인 전까지 확정된 것으로 표시하지 않습니다.
2. 보유 포지션의 손절·익절 및 청산 관리는 계속합니다. 일일 정지 자체가 모든 보유 주식을 즉시 강제 매도하는 명령은 아닙니다.
3. 알림을 DB와 대시보드에 남기고 콘솔에 출력합니다. Windows에서는 로컬 바탕화면 알림도 시도합니다. Windows 알림 정책 때문에 표시되지 않을 수 있으므로 대시보드·콘솔 기록도 확인합니다.
4. 같은 날 수동 재개나 프로그램 재시작으로 일일 정지를 해제할 수 없습니다. 주말에 초기화하지 않고 다음 거래일에 일일 한도와 횟수를 초기화합니다. 주문 불명확·장부 불일치 같은 장애 정지는 별도로 해결해야 합니다.

이메일·문자·메신저 전송은 기본 알림에 포함하지 않습니다. 사용자는 로컬 PC의 실행 상태와 알림을 확인해야 합니다.

실제 계정 주문·정산 및 Windows 바탕화면 알림은 사용자 환경에서 확인해야 합니다. 수수료·손절·익절·일일 한도 검증은 모의 HTTP 응답과 테스트를 포함한 개발 검증이며 실제 시장 수익성이나 손실 한도 준수를 보장하지 않습니다.
