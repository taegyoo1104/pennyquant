# 화면과 문서에서 쓰는 말

처음 보는 용어를 찾을 때 읽는 짧은 사전입니다. 실제 매매 순서는 [매매 과정](TRADING_PROCESS.md)에 설명되어 있습니다.

## 종목과 가격

| 용어 | 쉬운 뜻 | 이 프로젝트에서 읽는 방법 |
|---|---|---|
| 티커·종목 코드 | 주식의 짧은 이름. 예: AAPL | 회사 이름 대신 표와 요청에 사용하는 식별자 |
| S&P 500 | 미국 대형 기업 중심의 주가지수 | SPY ETF로 흐름을 참고. 현재 후보는 이 지수에 한정하지 않고 토스 제공 미국 상장 주식에서 선정 |
| 시가총액 | 주가와 주식 수로 본 회사 규모 | 감시 후보 최대 50개를 고르는 기준. 자료 미확인 기업은 제외 |
| 거래량 | 거래된 주식 수 | 100주와 1,000주를 비교하는 값 |
| 거래대금 | 거래된 주식의 금액 | 가격이 다른 종목 사이에서 거래가 활발한 정도를 볼 때 사용 |
| 호가 | 사람들이 사고팔겠다고 내놓은 가격 | 마지막 거래 가격과 다를 수 있음 |
| 매수호가·매도호가 | 사려는 가격·팔려는 가격 | 시장가로 살 때는 매도호가, 팔 때는 매수호가 쪽을 참고 |
| 스프레드 | 매수호가와 매도호가의 차이 | 차이가 크면 거래 비용과 불확실성이 커져 진입을 보류할 수 있음 |
| 유동성 | 원하는 때 거래하기 쉬운 정도 | 가격·거래량·거래대금·호가 잔량 등으로 참고 |
| 전일 대비 | 전 거래일 종가와 비교한 가격 변화 | 오늘 장 시작 가격과 비교하는 값과는 다름 |
| ETF | 여러 자산의 움직임을 따라가도록 만든 상장 상품 | SPY·QQQ 등은 시장 참고용. 현재 권장 단순 전략에서는 필수 입력이 아님 |

## 차트와 전략

| 용어 | 쉬운 뜻 | 예시·주의점 |
|---|---|---|
| 분봉·캔들 | 일정 시간의 가격과 거래량을 한 묶음으로 표시한 것 | 5분봉은 5분 동안의 자료를 묶음 |
| 시가·고가·저가·종가 | 구간의 첫 가격·가장 높은 가격·가장 낮은 가격·마지막 가격 | 15분봉 종가는 해당 15분 구간이 끝날 때의 가격 |
| 확정봉 | 해당 시간이 끝난 봉 | 진행 중인 봉은 아직 종가가 달라질 수 있어 신호에 쓰지 않음 |
| 상승 추세 | 가격이 올라가는 흐름 | 현재 규칙은 최근 두 확정 15분봉의 종가를 비교하는 간단한 정의 |
| 눌림목·조정 | 상승 흐름 중 잠시 가격이 내려오거나 쉬는 구간 | 이 프로젝트는 연속 1~4개 5분봉과 하락 폭으로 조건을 정함 |
| 반등 | 내려오던 가격이 다시 올라가는 것 | 현재 규칙은 5분봉이 직전 봉의 고가 위에서 마감했는지 검사 |
| VWAP·거래량 가중 평균가 | 많이 거래된 가격에 더 큰 비중을 준 평균 | 세션 VWAP는 정규장 시작부터 계산. 단순 산술평균과 다름 |
| EMA·지수이동평균 | 최근 가격에 더 큰 비중을 준 평균 | EMA9는 9개 봉을 기준으로 하는 평균선. 현재 구현에서는 5분봉 기준 |
| ATR·평균 변동폭 | 가격이 보통 얼마나 흔들리는지 나타내는 값 | ATR 0.8달러는 상승 확률이 아니라 변동 폭의 크기. 방향은 알려주지 않음 |
| RVOL·상대 거래량 | 평소 같은 시간까지와 비교한 오늘 누적 거래량 | 오늘 200만 주, 과거 평균 100만 주라면 2배. 현재 단순 전략에서는 필수 아님 |
| 추격 매수 | 이미 많이 오른 뒤 급히 따라 사는 것 | 상승했다는 사실만으로 매수하지 않고 조정·반등과 다른 조건을 검사 |
| 후보 점수 | 동시에 비교할 후보의 우선순위 | 성공 확률이나 합격 점수가 아님. 높은 점수도 필수 조건을 건너뛸 수 없음 |

봉을 묶는 시간 단위만 다를 뿐, 5분봉과 15분봉은 같은 원본 시세에서 나옵니다. 두 지표가 같은 방향이라고 해서 서로 독립된 증거 두 개를 확보한 것은 아닙니다.

## 주문과 돈

| 용어 | 쉬운 뜻 | 이 프로젝트에서 읽는 방법 |
|---|---|---|
| Paper·모의매매 | 실제 돈을 쓰지 않는 가상 거래 | 시세와 뉴스는 실제, 자금과 주문·체결은 가상 |
| 포지션 | 현재 보유 중인 주식 | 집중 목록에서 빠져도 보유 관리는 계속함 |
| 주문 | 사고팔겠다는 요청 | 주문이 만들어졌다고 보유 수량이 바로 생기지 않음 |
| 체결 | 주문의 일부 또는 전부가 거래된 것 | 여기서는 호가와 모의 규칙으로 계산한 가상 체결 |
| 미체결·부분 체결 | 아직 안 됨·일부만 거래됨 | 나머지 수량을 취소·재시도·만료 등의 상태로 추적 |
| 시장가 | 가격을 직접 지정해 기다리기보다 거래 가능한 가격으로 처리하는 방식 | 원하는 가격·전량 체결을 보장하지 않음 |
| 소수점 매매 | 1주보다 작은 수량을 거래하는 방식 | 예: 0.2주. 가상 처리 성공은 실제 계좌 가능 여부의 증명이 아님 |
| 슬리피지 | 기대한 가격과 체결 가격 사이의 차이 | 모의매매에서는 불리한 가격 차이를 가정해 비용에 반영 |
| 손절 | 손실이 커지기 전에 정한 조건으로 파는 것 | 매도 요청 후에도 자료 부족·미체결이면 잔량이 남을 수 있음 |
| 익절 | 이익이 난 상태에서 정한 조건으로 파는 것 | 현재 목표 이익은 비용을 차감한 순이익 기준 |
| 청산 | 보유 수량을 정리하는 것 | ‘청산 시도’와 ‘잔량 0, 완료’는 다름 |
| 원장 | 주문·체결·잔액·보유를 저장한 장부 | 프로그램 재시작 때 복구하고 결과를 검토하는 기준 |
| 위험 한도 | 한 번의 거래나 하루에 허용하려는 계획상 손실 범위 | 급변·체결 실패가 있어 실제 결과를 그 금액 이하로 보장하지는 않음 |

## 데이터와 AI

| 용어 | 쉬운 뜻 | 이 프로젝트에서 읽는 방법 |
|---|---|---|
| API | 다른 서비스에 자료를 요청하거나 받는 통로 | 토스 시세·뉴스·AI 분석 등을 연결 |
| REST·주기 조회 | 필요할 때마다 요청하고 응답을 받는 방식 | 분봉 보충·순위 조회 등. 여러 요청은 시간이 걸림 |
| WebSocket·실시간 연결 | 연결을 유지하며 새 자료를 받는 방식 | 현재 설정의 시세 수신에 사용. 분봉·뉴스까지 모두 같은 통로라는 뜻은 아님 |
| 예열·자료 준비 | 판단에 필요한 과거·당일 자료를 채우는 과정 | 화면이 열렸다고 준비가 끝난 것은 아님 |
| 신선도·지연 | 데이터가 얼마나 최근 것인지 | 수집 시각과 원본 시세 시각을 함께 봐야 함 |
| 미확인·UNKNOWN | 판단할 자료나 근거가 부족한 상태 | 위험 없음·거래 없음·악재라는 뜻으로 바꾸어 읽으면 안 됨 |
| RSS | 새 글 목록을 배포하는 형식 | 제목·링크만 있고 충분한 본문이 없는 경우도 있음 |
| 공시·SEC | 기업이 공식으로 알리는 정보·미국 증권 감독기관 | 공식 자료라도 새 내용과 해당 종목·원문 근거를 확인해야 함 |
| LLM | 글을 읽고 생성하는 AI 언어 모델 | 뉴스 사실 정리와 판단 해설에 사용. 주문은 코드 규칙이 결정 |
| 캐시 | 이미 받은 자료를 잠시 재사용하는 저장 공간 | 호출을 줄이지만 유효 시각·내용 변경을 확인해야 함 |
| 백테스트 | 과거 자료로 규칙을 다시 실행하는 검사 | 미래 수익을 보장하지 않으며 자료 누락·비용 가정에 영향받음 |
| 회귀 검사 | 수정 뒤 기존 동작이 깨지지 않았는지 확인하는 자동 검사 | 검사 통과와 실제 서버·외부 API 정상 운영은 별도로 확인 |

## 실행 환경과 개발

| 용어 | 쉬운 뜻 | 이 프로젝트에서 읽는 방법 |
|---|---|---|
| Codex·바이브 코딩 | 원하는 동작을 자연어로 설명하고 AI와 코드를 만드는 개발 방식 | 사람이 목표·규칙을 정하고 Codex의 구현을 검사·실행 결과로 확인 |
| DB·MySQL | 기록을 구조적으로 저장하는 곳·그 저장소 프로그램 | 시세·주문·체결 등을 보관하여 재시작 후 복구 |
| 실행 공간·namespace | 같은 DB 안에서 실행별 기록을 나누는 이름 | 다른 실험 장부와 섞이지 않게 구분. 이름을 바꿨다고 기존 보유가 청산되지는 않음 |
| VM·GCP | 빌려 쓰는 가상 컴퓨터·Google의 클라우드 서비스 | 내 PC와 별도로 앱과 DB가 실행되는 서버 |
| Docker·컨테이너 | 프로그램과 필요한 환경을 한 묶음으로 실행하는 도구·실행 단위 | 앱과 MySQL을 각각 실행. 컨테이너 상태와 매매 준비 상태는 다름 |
| Cloud Shell | Google이 브라우저에서 제공하는 작업용 터미널 | 운영 VM과 별도의 컴퓨터. 서버에 접속하고 화면 연결을 열 때 사용 |
| SSH·터널 | 원격 서버에 접속하는 통로·그 통로로 특정 연결을 전달하는 기능 | 서버의 대시보드를 내 브라우저에 연결. 터널 종료와 VM 종료는 다름 |
| tmux | 접속이 끊겨도 터미널 작업을 유지하도록 돕는 도구 | 업데이트 작업을 이어서 확인. VM이 꺼지면 유지되지 않음 |
| CI·회귀 검사 자동화 | 코드를 바꿀 때 자동으로 검사하는 과정 | 기존 규칙이 깨지지 않았는지 확인. 운영 서버 배포와는 별개 |
| CD·배포 | 검증한 새 버전을 서버에 적용하는 과정 | 현재 수동 배포이며 버튼식 자동화는 추후 작업 |
