# SessionQuant 방향과 단계 경계

확인일: 2026-11-15. 사용자 요청으로 과거 대화와 단계별 첨부를 현재 코드와 대조했다.

## 확인한 자료

- [이전 Codex 대화]([private conversation link removed]): 공개 공유 대화 본문을 읽었다. PennyQuant에서 SessionQuant로 전환한 목적, 로컬 MySQL·Paper 우선, 토스 연결과 단계별 작업 이력을 확인했다. 개인 접속 정보와 대화 전문은 저장소에 복사하지 않는다.
- [기획 대화]([private conversation link removed]): 이번 환경에서는 HTTP 503/timeout으로 본문을 읽지 못했다. 이 링크를 확인 완료한 근거로 삼지 않는다.
- 사용자가 다시 제공한 16개 첨부: 읽는 순서, 전체 로드맵, 00 기준선, 01~10 단계, 08A, 06·07 개정, 금리·유가 개정. 현재 요청은 **07 수행**이다. 첨부의 후속 단계 지시는 해당 단계의 참고 요구사항으로 보존한다.
- [HANDOFF](../HANDOFF.md)의 06 후속 검증 완료 기준 `0fa5ad4`에서 이어서 작업했다. 첨부의 과거 기준 커밋으로 현재 작업을 되돌리지 않았다.

## 유지할 목표

S&P 500 장중 추세 매매를 개발한다. 시가총액 감시 최대 100종목에서 집중 최대 20종목을 선정하고, 확정된 5분·15분봉, SPY·QQQ 국면, 거래 적격성·RVOL, 비중·위험·청산 조건을 함께 확인한다. 뉴스 없이도 기술적 조건으로 후보가 될 수 있다. 현금 유지와 무거래도 정상 결과다.

토스는 시세·계좌·주문 연결 경로로 유지한다. **KIS 검토·연결은 사용자 취소를 반영해 범위에서 제외한다.** 주문 전달과 체결, 실제 보유와 Paper 장부를 구분하며 실계좌 값을 합성 데이터로 채우지 않는다.

기업·거시 뉴스와 LLM은 사실과 위험 분석을 보조한다. 제목·발견 목록·출처 미확인 자료로 확정 사건을 만들지 않는다. LLM에는 주문 도구를 제공하지 않는다. 키·크레딧·뉴스가 없거나 분석에 실패해도 차트 처리와 기존 포지션의 손절·청산 작업은 독립적으로 진행한다. 이미 검증된 위험 제한은 유지한다.

FRED 금리·유가 자료는 일별 배경, IEF/TLT/SHY/USO 등은 장중 ETF 대용 지표다. ETF 수익률을 금리 bp나 원유 현물 가격으로 환산하지 않는다. 선택적 이벤트 LLM 해설은 기본 OFF이며 자동 주문·강제 청산에 연결하지 않는다.

## 개발 순서와 현재 범위

로컬 MySQL 8 + Paper에서 기록·관찰·검증한 뒤, 별도로 승인한 토스 소액 실거래를 검증하고 마지막에 GCP 이전을 검토한다. 기능 구현, 실제 계정 접근, 장기간 성과 검증, 운영 승인은 각각 따로 확인한다.

| 단계 | 현재 상태 |
|---|---|
| 00~05 | 기존 구현·기준 유지. 현재 트리에 CI 워크플로가 없어 자동 CI 운영은 별도 미완료 항목 |
| 06 | `0fa5ad4`의 격리 회귀 검증 완료 기준 유지. 실제 공급자 운영 조건은 미검증 |
| 07 | 사용자 승인 범위. [LLM 감사·근거·평가·비용 구현](STAGE07_LLM.md) 및 격리 검증 |
| 08 / 08A | 종목순위·뉴스·포트폴리오 및 전체 UI·매매제어 개편은 다음 승인 대기 |
| 09 / 10 | 공통주문·실거래 연결·로컬 운영 승인은 다음 승인 대기 |
| GCP | 로컬 검증·운영 승인 이후 별도 검토 |

07에서는 기존 메인 5개 탭을 보존하고 비용 카드를 간결하게 정리하며 기존 LLM 상세에 감사 조회를 추가한다. 08A 전체 화면 개편을 함께 수행하지 않는다. 과거 문서의 **Phase 5 실거래 기능**과 새 로드맵의 **05 기록·백테스트**는 번호 체계가 다르므로 파일의 실제 기능과 실행 경로를 확인한다.
