# 검증 기록

검증 환경: Python 3.12.14, Linux, PennyQuant 0.1.0. 의존성의 정확한 버전·해시는 requirements.lock에 고정했습니다.

## 통과한 검사

- 전체 pytest **166개 통과**: 뉴스·스캐너·네 전략, 동시간 RVOL, 위험·정수 수량·거래시간, 부분 체결·중복·취소·손절, 수집기 HTTP 모의 응답, 스트림 선언, SQLite·재시작·파일 변경·시계 검증, Streamlit 화면·제어.
- Ruff 검사와 Python 모듈 컴파일 통과.
- 합성 데이터 810개 이벤트, 뉴욕 10개 세션을 네 전략에 같은 자본·비용·유동성 조건으로 처리. 앞 6개/뒤 4개 세션을 독립 비교. 모든 전략에 실제 가상 체결·비용·완료 거래가 생성됨.
- 브라우저(Playwright Chromium)에서 네 탭, 신규 진입 중지·재개, 합성 데이터 표시, 전략 표·그래프 렌더링 확인. 페이지 JavaScript 오류 0건. 화면을 눈으로 검사해 내부 객체 설명 노출을 수정하고 회귀 검사 추가.
- 배포용 Python wheel 빌드 및 별도 가상환경에서 해시 잠금 의존성 설치 확인. 설치 패키지의 doctor·데모를 프로젝트 소스 디렉터리 밖에서 확인.

`exchange-calendars`가 사용하는 pandas API에서 향후 pandas 4 동작 변경 안내 8건이 출력됐습니다. 검사 실패는 없었으며, 잠금 버전에서 휴장·단축장·DST 테스트를 통과했습니다. 의존성을 갱신할 때 재검증하세요.

## 주요 장애·복구 검증

| 상황 | 확인한 결과 |
|---|---|
| 같은 신호 재호출 | 기존 주문 반환, 추가 주문·체결 없음 |
| 주문 ID의 내용 충돌 | 신규 진입 차단 |
| 주문 생성에 사용한 호가 재수신 | 같은 시점에서 체결하지 않음 |
| 동일 시장 timestamp 호가 중복 | 표시 수량을 다시 사용하지 않음. 재시작 후에도 유지 |
| 부분 체결·미체결 잔량 취소 | 현금·예약금·실제 보유 수량 일치 |
| 수동 중지·일일 손실 중지 | 신규 매수 제한, 유효 호가의 보유 수량 출구 관리 계속 |
| 주문 unknown·포지션 불일치 | 무조건 재주문하지 않고 중단 |
| 복구 후 최신 호가 | 옛 스캐너 snapshot으로 최신 평가가격을 덮어쓰지 않음 |
| 같은 경로에서 기록 파일 변경 | 전체 SHA-256 불일치로 재개 거절 |
| 소비한 실시간 파일 앞부분 변경 | 오프셋 앞부분 해시 불일치로 복구 거절 |
| 기록 재생 DB를 실시간 DB로 재사용 | 런타임 모드 불일치로 거절 |
| 오래된 입력을 실시간으로 읽음 | 현재 시각 검사로 과거 호가 체결 차단 |
| 저장 도중 예외 | 주문 저널·스냅샷 트랜잭션 함께 롤백 |
| 거래 가능 불리언 누락·문자열 입력 | 자동 승인 기본값으로 진입하지 않음 |
| 누락 동시간 과거 거래량 | RVOL 미확인, 진입 차단 |
| 미래 뉴스·발표 이전 반응·수신 지연 | 진입 신호에 사용하지 않음 |

## 검증하지 않은 범위

실제 토스 인증·계좌·시세 권한·IP 등록, Alpaca 계정별 실시간 권한·실제 구독, 제공자 실제 응답의 계정별 차이, 실주문·취소·OCO, 거래소 대기순서·깊이, 실제 비용·환전·규제 수수료, Docker 이미지 빌드, VM 재부팅·장기간 부하·실시간 4주 검증은 수행하지 않았습니다.

수집기 단독 출력은 거래 가능 상태·과거 RVOL·완전한 snapshot이 부족합니다. 실시간 자동화에는 검증한 데이터 생산자의 연결 작업이 남습니다. 이 제한을 우회해 누락 값을 긍정적인 값으로 채우지 않습니다.

예시 보고서의 수익·손실은 손으로 정한 합성 경로에서 발생한 결과입니다. 전략의 순위·수익성·실거래 승인을 뒷받침하는 자료가 아니며, 실제 시장 성과 보고서는 아직 없습니다.

## 재현

```bash
python -m pytest -q
ruff check .
python -m compileall -q pennyquant
python -m pennyquant demo --out data/validation
```

생성된 JSON·Markdown은 examples/report.json·report.md와 같은 구조입니다. 생성 시각은 실행마다 바뀌지만 합성 테이프와 계산 결과는 결정적입니다.
